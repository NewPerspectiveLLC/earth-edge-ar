# Live Geometry — Matt's Reality

**Live Geometry** is the app. **Matt's Reality** is its world, also known as **Ready Security Services Map 1 · Base Geometry Reality**.
Web AR built with Three.js (iPhone/desktop `index.html`, Meta Quest `quest.html`, game master `gm.html`, live figure dashboard `figures.html`) around Port Townsend, WA.
It is a web app: there is no app store listing. Add it to the home screen from the browser (manifest name "Live Geometry").

Repo, Pages path and server folder keep the historical id `earth-edge-ar` (URLs, storage keys and `EEAR_*` globals are unchanged on purpose).

## d44: Matt Ready pillars
- `pillars.json`: ~100 public spots (OSM street-corner right-of-way, parks, landmarks, trails), generated by stratified sampling; never private lots.
- `pillars.js`: one shared triangular prism (1.8 m tall, 0.7 m sides) InstancedMesh, the same image (`PILLARS.image` in `figures-registry.js`, default `pillar-matt.jpg`) on all three faces; a pillar entry may carry its own `"image"`.
- Every pillar plays the Disco Jam from its spot (HRTF), full volume within 3 m, raised-cosine fade to silence at 55 m; only the nearest 2 pillars get a voice; one shared decoded buffer and one loop clock; the Garden beacon ducks by 80% while a pillar is audible. Needs Music on (tap), like the beacon.
