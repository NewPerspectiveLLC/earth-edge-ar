# Live Geometry — Matt's Reality

**Live Geometry** is the app. **Matt's Reality** is its world, also known as **Ready Security Services Map 1 · Base Geometry Reality**.
Web AR built with Three.js (iPhone/desktop `index.html`, Meta Quest `quest.html`, game master `gm.html`, live figure dashboard `figures.html`) around Port Townsend, WA.
It is a web app: there is no app store listing. Add it to the home screen from the browser (manifest name "Live Geometry").

Repo, Pages path and server folder keep the historical id `earth-edge-ar` (URLs, storage keys and `EEAR_*` globals are unchanged on purpose).

## d44: Matt Ready pillars
- `pillars.json`: ~100 public spots (OSM street-corner right-of-way, parks, landmarks, trails), generated by stratified sampling; never private lots.
- `pillars.js`: one shared triangular prism (1.8 m tall, 0.7 m sides) InstancedMesh, the same image (`PILLARS.image` in `figures-registry.js`, default `pillar-matt.jpg`) on all three faces; a pillar entry may carry its own `"image"`.
- Every pillar plays the Disco Jam from its spot (HRTF), full volume within 3 m, raised-cosine fade to silence at 55 m; only the nearest 2 pillars get a voice; one shared decoded buffer and one loop clock; the Garden beacon ducks by 80% while a pillar is audible. Needs Music on (tap), like the beacon.

## d45: Master DJ
- One global queue for everyone (server `/api/dj`, SSE `/api/dj/stream`; GM-key writes from `dj.html`). Library `audio/dj/library.json` (24 Kevin MacLeod CC BY 4.0 + Disco Jam). `dj.js` streams the current track synced to server time; pillars + the in-app music player (track "Master DJ", default) play it.

## d46: Flying sound + orb
- `orbit.js`: the Master DJ in the music player orbits the listener (HRTF, world-anchored): wander 10-16 m out / 11-14 m up, lingers (3-15 s, closer, +5 dB), excursions to 30-60 m; distance law (12/r)^0.8, floor 0.22. Toggle "🌀 Flying sound" in the music panel (⋯); off = plain playback via the Garden beacon chain.
- `orbball.js`: 10 m neon-purple plasma orb at the same position (fbm fire shader + fresnel rim, flame corona, 2 halos, ember trail, beat pulse; LOD on phones/Quest and when far), `orb-matt.jpg` (Project Driftwood, unmodified) billboard 7 m tall under it, and one client-only spawn copy 6-10 m from each player at their first fix (never sent anywhere).
- Pillars: `PILLARS.images` per face (2x `orb-matt.jpg`, 1x `pillar-matt.jpg`), fitted unstretched with neon-purple bands.

### d46c — flying-sound trail tours
Every 2.5–4 min (first one 75–120 s after load) the Master DJ source leaves its orbit, flies out (90 m/s cap, 6–28 s, arcing up mid-flight), loops a real trail from `trails.json` (OSM paths; alternates **Ready Athletics trail** and **Cappy's trails**, 14–45 s at ≥28 m/s, 18 m above eye level), then flies back into the orbit. Skipped when the site is > 6 km away. Gain follows the same distance law (floor 0.22, never silent). Constants: `ORB.tour` in `orbit.js`. The orb is never frustum-culled (pure perspective shrink); LOD drops one more fbm octave beyond 300 m.
Also d46b: place light beams write alpha = brightness, so in camera mode (normal blending) a beam you stand inside no longer paints opaque black over the sky/orb.

### d46d — blue-blur fix
Orb glow materials add alpha (valid premultiplied canvas on iOS), halos capped to the ball's on-screen size, ember point size ≤ 40 px; player/bot beams fade out within 3–20 m.

### d47 — Ghost controls, Pick song for everyone, live DJ voice
- **Ghost controls** (`ghostctl.js`, `ghost.html`, in-app "👻 Ghost controls" under the Ghost bot buttons): mode classic/orbit/follow/wander/mirror, speed min/max, distance min/max, direction, loop radius, float height, jitter, pause frequency/length, follow lag, shy↔bold, opacity, size, glow, trail; presets Calm/Playful/Shadowing/Wild + Reset. localStorage `eearGhostCfg`; client-only (the ghost is never sent to the server).
- **Pick song for everyone** (`djpanel.js`): ⋯ music panel "🎧 Pick song for everyone" or tap the Now-playing pill. Library ▶ Now / + Next, queue ▶ Now, Prev / Pause / Next via the GM-key `/api/dj` (key asked once, `localStorage.eearGM`).
- **Live DJ voice** (`djvoice.js`, server `/api/dj/live`, `/api/dj/bc`): Go live streams 16 kHz PCM in 400 ms chunks over the existing SSE `/api/dj/stream` (event `pcm`), played gap-free with a 0.35 s jitter buffer; music ducks to 20 %; voice comes from the orb when Flying sound is on. Each session is saved as `server/broadcasts/<id>.wav` (not data.json; last 40 kept); repeat 1–10× with a gap, Replay last, Stop broadcast now (cancels for everyone).
- **d47b long-poll fallback**: the trycloudflare quick tunnel (and so the Pages copy) buffers SSE, so voice chunks and DJ state changes never arrived through it. Clients now also hold `GET /api/dj/pull?after=<gs>&rev=<rev>` (answered at once on a new chunk / state change, else after 12 s); chunks are de-duplicated by id:seq when SSE also delivers them (LAN).

## d48: Quest pass, orb 25 m rule, Ren usage guard, Room Stats

### Quest controls (`quest.html`)
- **Trigger = fast flight** (hold to fly at high speed where you point; intentionally fast, do not slow it down).
- **🔒 Padlock** (A / trigger at start) = position + north lock; **B** unlocks.
- **Powers** (in-VR panel → Powers; local to this headset only, never affect real players): **right thumbstick click** cycles weapon Freeze (water gun) → Web lock → Tow line; **A** (or right grip) fires; **long-press A** = Freeze: thaw all · Web: clear the aimed web · Tow: release. With Powers on and north locked, A fires instead of boarding the ship (board from the panel).
  - **Freeze**: water jet (≤30 droplets, gravity arc, splash); the hit being freezes in an icy faceted shell for 60 s (shoot again to thaw; thaw = crack + shatter).
  - **Web lock**: sticky catenary strand; the being is wrapped in a pearly cocoon and held at that spot until cleared (persists across reloads in this headset's localStorage).
  - **Tow line**: taut glowing strand; the being keeps moving and you are smoothly dragged 3-5 m behind it (one tow at a time; fire again or long-press to release; auto-release if it disappears; overrides the padlock while active).
  - Targets: the 12 edge bots, Ren, ghosts / Matt's Shadow, performers.
- **North tools** (panel → Powers): *Set north = where I'm facing* (persisted), *Nudge north ±5°*, *Reset north*.
- **Lite mode** (default on for Quest; panel → View, or `?lite=0/1`): 0.8x XR framebuffer, max foveation, 72 Hz, merged static lines/tubes, lighter vortex tubes, instanced saucer lights, 2-octave orb, 40 embers. Draw calls ~1960 → ~850 headless.
- Music auto-starts on Enter VR (unless turned off), resumes on the first select/squeeze; an in-VR "Now playing" line sits under your view.
- The 12 edge bots roam toward Ready Athletics on Quest: players farther than 150 m are drawn 150 m away on their true bearing, so the bot ring (about 1.2 km away) walks along with you. This is kept on purpose.

### Orb hard rule (all pages)
The orb's center never comes closer than **25 m (3D) to the camera** in any phase (orbit 25-34 m, lingers, swoops, trail returns, overhead passes, fast flight). A final push-out runs every frame; the close-fade stays as a backstop. Linger loudness comes from gain (reference distance 25 m), not from getting closer.

### Ren AI usage guard (server)
- Every Ren call is logged to sqlite `server/eear.sqlite` (table `ren_usage`; also `ren_alerts`, `ren_first`) and to `logs/ren-usage.jsonl` (rotates at 5 MB, keeps 3). Players are anonymous ids (salted hash).
- Caps live in `~/.eear-secrets/ren-limits.json` (chmod 600; re-read on change; GM-editable on gm.html → Ren usage). Defaults: $1/day, $10/month, warning at 80 %, 30 requests/player/hour, 200/player/day, 60/min globally, max_tokens 300, plus an AI on/off switch. When a cap is hit, Ren gives canned replies until the next PT day or month.
- Prices (per 1M tokens) are in the same file, taken from docs.x.ai/docs/models (2026-10-18).
- GM endpoints (header `X-GM-Key`): `GET/POST /api/ren-usage`, `POST /api/ren-usage/test-notify`, `GET /api/stats`.
- First-contact notifier: `~/.eear-secrets/ren-notify.json` (chmod 600, never committed), off until the file exists. Examples: `{"mode":"imessage","to":"+1..."}` or `{"mode":"webhook","url":"https://...","authorization":"Bearer ..."}`; optional `"alerts":true`, `"maxPerHour":30`, `"enabled":false`.
- `stats.html`: "Room Stats" dashboard (GM key, refreshes every 10 s).

## d50 (2026-10-19): Matt Ready Drive-in screen (Videos on Loop)
- `drivein.js` (index.html + quest.html): a giant double-sided outdoor movie screen floating over the Hood Canal Bridge (facing Seattle); was formerly over the Port Townsend peninsula north of
  downtown. Centre **48.1300, -122.7650**, **340 m** above ground, picture **480 x 270 m** (16:9) in an 8 m dark frame with gold trim,
  a "MATT READY DRIVE-IN" marquee (readable from both sides) and a soft glow (glow skipped in Quest Lite). Front faces bearing 190° (SSW,
  between downtown and Ready Athletics); the north side shows the same picture mirrored (DoubleSide video plane), never a black back.
  ~1.9 km NNW of downtown Water St, ~4.0 km NE of the RA vortex. All constants: `DRIVEIN` at the top of drivein.js.
- Video: Drive `My Drive/Matt Ready Library/videos on loop` (read-only) -> `tools/video_sync.py` -> one reel
  `video/drivein/reel-<hash>.mp4` (1280x720 H.264 High + AAC, faststart, 1 s GOP) + `reel-<hash>-lite.mp4` (640x360, Quest Lite) +
  `video/drivein/screen.json` (epoch, duration, clip table). Every clip is fitted unstretched (black bars), loudness -16 LUFS.
- Sync: everyone sees the same frame: pos = ((serverNow - epoch)/1000) mod duration; serverNow uses the Master DJ clock offset (dj.js).
  Drift > 0.8 s is corrected by a seek (at most every 4 s). Needs HTTP byte ranges (Mac server + Pages both do).
- Sound: muted by default (iOS autoplay = muted + playsinline). **Screen sound** (Layers sheet button / XR + Quest panel 'Places ->
  Drive-in screen sound', localStorage.eearScreenSound) is the master switch; spatial gain on top, from the viewer's GPS/world position
  to the NEAREST point of the screen (d50b): gain = 1 for d <= 5 mi (8047 m); then g = ½(1 + cos(π(d-8047)/(16093-8047))); 0 beyond
  10 mi (16093 m). 1 mi 1.00 · 5 mi 1.00 · 7 mi 0.65 · 8 mi 0.35 · 10 mi 0.00. Desktop/Quest/Android: the video element's own output with
  v.volume = gain (d50b fix: the WebAudio route left desktop silent). iOS: MediaElementSource -> gain -> HRTF panner -> app master volume.
  Never ducks the DJ music.
- Far marker: beyond ~9 km (fading in from 7.5 km) a gold "🎬 DRIVE-IN · x mi · y km" billboard with a down-arrow, fixed angular
  size, always drawn on top exactly in the screen's direction (Quest far plane is 10 km). iPhone/desktop also get an edge-of-view arrow
  when it is off screen (hidden with the other UI in hide-all-buttons mode; the 3D marker stays).
- Toggles: Layers checkbox **🎬 Drive-in screen** (iPhone/desktop, both rooms, on by default), XR panel + Quest panel **Places -> Drive-in
  screen**. Server: `.mp4` added to the static allowlist + `video/mp4` MIME (server.js).
- Adding videos: see `/workspace/videos/loop_sync/README.md` (`python3 tools/video_sync.py plan|apply|status`, idempotent, not scheduled).
